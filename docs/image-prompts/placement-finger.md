# Finger tattoo gallery image prompts

Generation mode: built-in image generation, default quality.

Shared direction: photorealistic vertical 3:4 editorial macro photographs of one adult hand and fingers against a neutral studio background. Every tattoo must look healed, fit the finger anatomy and remain clearly visible. Use realistic joints, nails, skin texture, soft directional light and exactly five fingers. Exclude rings, jewelry, text, letters, numbers, logos and watermarks.
